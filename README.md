## 🌟 संकल्पना (The Concept)

हा प्रकल्प कोणत्याही तांत्रिक किंवा क्लिष्ट अभ्यासक्रमाचा ब्लॉग नाही; हा **पठाण सरांचा वैयक्तिक विचार-कोष (Curated Wisdom Stream)** आहे.

येथे जगातील सर्वोत्तम प्रेरणादायी कोट्स, विचार करायला लावणारे पॉडकास्ट्स, संस्मरणीय युट्यूब व्हिडिओज आणि जीवनदृष्टी देणारे विचार अतिशय सोप्या, सुंदर आणि अभिजात (Editorial) स्वरूपात मांडले जातात.

## ✍️ नवीन विचार कसा पोस्ट करावा? (GitHub Web द्वारे)

पठाण सर थेट मोबाईल किंवा कॉम्प्युटरवरून नवीन पोस्ट टाकू शकतात:

1. तुमच्या GitHub Repository मध्ये `src/content/posts/` फोल्डर उघडा.
2. **"Add file"** ➔ **"Create new file"** निवडा.
3. फाईलचे नाव इंग्रजीत द्या (उदा. `steve-jobs-stay-foolish.md`).
4. खालीलपैकी एका फॉरमॅटचा वापर करा:

### १. सुविचार / Quote पोस्ट:
```markdown
---

date: "2026-11-15"
category: "Quote"
author: "पठाण सर"
quoteText: "Stay Hungry, Stay Foolish."
source: "Steve Jobs (Stanford Commencement)"
description: "आयुष्यात शिकण्याची भूक कधीही संपू देऊ नका."
---

येथे पठाण सरांचे या विचारावरील मनोगत लिहा...
```
